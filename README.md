## 🧠 My Learning Philosophy

I don't want to just memorize syntax.

I try to understand:

> **Why does this work? How does it work? And where can I actually use it?**

Whenever I get stuck, I try to break the problem into smaller pieces, understand the error, fix it, and then try again.

I believe that programming is less about knowing everything and more about being able to **learn, experiment, debug, and keep improving.**
